# Daily SOAP website

Landing page for the Daily SOAP Bible reading app, served at https://dailysoap.app via GitHub Pages.

## Layout

- `index.html` - the page
- `css/landing.css` - styles
- `js/features.js` - features section behavior
- `img/` - app icon, screenshots, store badges
- `favicon/` - favicons and web manifest
- `docs/HANDOFF.md` - design spec

## Preview

There is no build step. Open `index.html` in a browser, or run any static server, for example `python3 -m http.server`.
